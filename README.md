- `index.html`: el altar completo. Al abrirlo se ve el formulario; con `#altar` al final de la dirección, la pasarela del proyector.
- `config.js`: dirección y llave pública del proyecto de Supabase.
- `supabase.sql`: crea la tabla, la carpeta de fotos y las reglas. Se pega una vez en Supabase → SQL Editor.

## Quitar una ofrenda
Supabase → Table Editor → `ofrendas` → selecciona la fila → Delete.

## Después del 2 de noviembre
Borra la tabla y la carpeta `fotos` en Supabase (o el proyecto completo), y archiva o borra el repositorio.
